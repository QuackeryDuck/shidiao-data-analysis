# 交付前质量清单

用法：生成文档后逐项检查。标 **[阻断]** 的项不通过，不得交付。每项记录“通过 / 不通过 / 待确认”和证据位置（章节号）。

## A. 输入与一致性

- [ ] **[阻断]** 输入文件路径正确，能被 `validate` 解析，无 fatal error。
- [ ] **[阻断]** 项目名称、目标总体、研究区域、调查单位完整且互不矛盾。
- [ ] 数据来源与研究方法匹配（例如没有文本数据却推荐情感分析）。
- [ ] 样本参数与研究设计匹配（分层/整群/便利抽样是否体现在设计效应中）。
- [ ] 输入中的方法偏好已在第 5 章得到回应；不采用时说明原因。
- [ ] 第 10 章列出所有默认值与推断项。

## B. 研究问题与假设

- [ ] **[阻断]** 每个 RQ 都能在假设表或探索性问题中找到落点。
- [ ] **[阻断]** 假设的 IV、DV、中介、调节与研究问题一致，无角色重复。
- [ ] 差异类问题使用分组变量；影响类问题使用 IV→DV；中介/调节路径完整。
- [ ] 每个假设有方向（正向/负向/存在差异/待检验），方向有理论或文献依据。
- [ ] 每个假设有检验方法，且与第 5 章模型一致。
- [ ] 理论依据具体到机制，不是“消费者行为理论”一句套话。
- [ ] 无法检验的问题被明确列为探索性，不强行包装成假设。

## C. 变量

- [ ] **[阻断]** 每个核心构念有角色、操作化定义、测量层级、题项数、数据来源。
- [ ] **[阻断]** 因变量是结果变量，不是原因、分组变量或中介变量。
- [ ] 每个构念的题项数足够（量表构念 ≥3 题）。
- [ ] 李克特题项同向；反向题已标注并说明转换规则。
- [ ] 控制变量有纳入理由，数量合理（通常 3–6 个）。
- [ ] 筛选变量、质控题与核心变量分开，不混入模型。
- [ ] 变量字典字段名与问卷题号、数据集字段一致。
- [ ] 没有遗漏关键变量（价格、便利性、竞争品牌、使用场景、信任、风险等）。
- [ ] 3.10 变量—模型映射没有把无关变量塞进模型。

## D. 样本与抽样

- [ ] **[阻断]** 目标总体可定义、可接触；抽样框或抽样途径可操作。
- [ ] **[阻断]** 样本量公式、参数、计算结果三者一致。
- [ ] 有限总体修正使用正确（提供 N 才修正；N 很大时影响很小）。
- [ ] 设计效应有依据（分层/整群/便利抽样通常 >1）。
- [ ] 有效回收率有预调研或经验依据，计划发放量 = 有效样本 / 有效率。
- [ ] 分层配额合计 100%，每层可达，且与渠道能力匹配。
- [ ] **[阻断]** 每个核心模型的最低样本要求都满足；不满足时有补样或降级方案。
- [ ] 敏感性分析覆盖置信水平与允许误差的合理组合。
- [ ] 文本/二手数据的采集规模与用途匹配（如 LDA 需要 ≥500 条）。

## E. 模型（重点）

- [ ] **[阻断]** 5.3 每个 RQ 至少一个主模型，且模型与问题类型匹配。
- [ ] **[阻断]** 每个核心模型都能追溯到一个 RQ 和一组变量。
- [ ] **[阻断]** 模型条目包含：定位、RQ、变量、适用理由、公式/口径、步骤、前提、结果解读、备选。
- [ ] 模型前提可检验（正态、方差齐、VIF、KMO、期望频数、EPV 等）。
- [ ] 前提不满足时有明确备选，而不是删数据或改结论。
- [ ] 高阶模型有本科生可执行的降级方案。
- [ ] 核心模型数量在 6–12 个之间（纯问卷通常 6–10 个）；没有“为用模型而用模型”。
- [ ] 定序因变量、二分类因变量、多重响应数据的模型选择正确。
- [ ] 中介/调节模型说明了横截面数据的因果限制。
- [ ] 没有把相关分析写成因果结论。
- [ ] 软件与代码建议可实现（SPSS/Python/R/Excel 与团队能力匹配）。

## F. 调查渠道

- [ ] **[阻断]** 渠道能触达目标总体，不是只列平台名称。
- [ ] 主/辅/补充/备用渠道分工明确。
- [ ] 每个渠道有目标样本、触达方式、成本、负责人、时间。
- [ ] 线上样本的覆盖偏差被识别，并有线下/配额校正。
- [ ] 投放节奏与周期、预算、团队人数一致。
- [ ] 二手数据与文本来源有获取方式、时间范围、口径说明。
- [ ] 合规：知情同意、隐私、平台条款、版权、数据存储。
- [ ] 不抓取个人信息，不绕过平台限制。

## G. 质控

- [ ] **[阻断]** 质控覆盖设计、抽样、执行、清洗、分析、交付六阶段。
- [ ] 无效问卷规则可执行，阈值有依据（时长、直线作答、逻辑矛盾、甄别题、重复 IP）。
- [ ] 清洗规则说明缺失值、异常值、反向题、多选拆分、文本去重。
- [ ] 分析阶段质控包括前提检验、异常值影响、稳健性、多重比较。
- [ ] 质控责任落到角色，检查点有时间。
- [ ] 验收标准量化（有效样本、完成率、逻辑错误率、信度下限、缺失率上限）。
- [ ] 伦理与数据安全要求具体（匿名、脱敏、授权、保存期限）。

## H. 交付与可复现

- [ ] **[阻断]** 数据集结构覆盖分析所需全部字段。
- [ ] 字段命名、编码、缺失值编码统一。
- [ ] 数据版本、代码版本、文档版本可对应。
- [ ] 交付清单包含问卷、数据、字典、代码、文档。
- [ ] 图表能从数据与代码复现，不是截图。
- [ ] 参考文献格式统一，正文引用与附录一致。

## I. 写作与格式

- [ ] Markdown 渲染正常，表格列数一致，Mermaid 可显示。
- [ ] 章节编号连续，交叉引用（如“见 4.3”）指向正确。
- [ ] 数字前后一致（摘要、正文、表格中的样本量相同）。
- [ ] 没有“可能”“大概”“也许”等模糊表述；不确定处写“待确认”。
- [ ] 没有编造文献、数据、统计结果或平台政策。
- [ ] 全文术语统一（如“购买意愿”不混用“购买意向”）。

## J. 答辩视角

- [ ] 能用一句话说明“为什么做这个研究”。
- [ ] 能用一句话说明“样本为什么够”。
- [ ] 能用一句话说明“每个核心模型为什么选它”。
- [ ] 能回答“如果前提不满足怎么办”。
- [ ] 能回答“数据质量怎么保证”。
- [ ] 能回答“研究局限是什么”。

---

## 评分建议

| 等级 | 标准 |
| --- | --- |
| 可交付 | 所有 [阻断] 通过，其余不通过项 ≤3 且已标注待确认 |
| 需修改 | 任一 [阻断] 不通过，或关键章节只有标题没有内容 |
| 不可用 | 变量角色系统性错配、模型与 RQ 大面积不对应、样本量明显不足且无说明 |

交付时附一句：“本文件为研究设计基线，不含统计结果；第 10 章列出需团队确认的事项。”
