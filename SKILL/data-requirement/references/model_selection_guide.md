# 模型选择指南（35 个方法）

用于回答两个问题：**这个研究问题该用什么模型**，以及**为什么不用另一个模型**。

选模型的顺序不是“哪个高级用哪个”，而是：

1. 研究问题要回答什么（描述、差异、关联、影响、机制、分群、评价、预测、文本）？
2. 因变量与自变量的测量层级是什么（定类、定序、连续、文本、多重响应）？
3. 数据怎么来（问卷、公开文本、二手数据、实验）？
4. 样本量够不够模型的最低要求？
5. 前提假设能否检验、不满足时有没有备选？
6. 本科生团队能否在比赛周期内正确执行并解释？

任何一步不满足，就降级到更稳妥的方法，而不是硬上。

## 1. 按研究问题选模型

### 1.1 描述现状

- 单变量分布、集中趋势、离散程度 → **描述性统计**
- 态度、意愿、感知等多题项测量 → **李克特量表** + **Cronbach's α**
- 多选、消费场景、品牌提及 → **交叉分析（多重响应）**
- 市场关注度的时间/地域趋势 → **百度指数分析**

### 1.2 组间差异

- 因变量为连续变量，分组为 2 组以上 → **方差分析（ANOVA）**
- 因变量为分类变量 → **卡方检验** + **交叉分析**
- 需要控制协变量 → 回归模型中加入分组虚拟变量（不要误用多次 t 检验）
- 分组后样本很小或方差不齐 → Welch ANOVA / Kruskal-Wallis（ANOVA 的备选）

### 1.3 变量关联

- 两个分类变量 → **卡方检验** / **交叉分析**
- 多个多选题的选项共现 → **关联规则分析**
- 连续变量之间的关系 → 相关分析 + **多元线性回归**（相关本身不是因果）

### 1.4 影响因素

- 因变量连续、关系近似线性 → **多元线性回归**
- 因变量二分类（买/不买、愿意/不愿意） → **二元 Logistic 回归**
- 自变量多、共线性强、需要筛选 → **弹性网络回归**
- 关系非线性、样本较大、以预测为主 → **随机森林** / **LightGBM**
- 潜变量、测量误差、路径关系 → **结构方程模型 SEM**

### 1.5 中介与调节

- 中介：X → M → Y，理论上路径清晰 → **SEM** 或回归 + Bootstrap
- 调节：W 改变 X 对 Y 的影响 → 分层回归（交互项）；复杂模型可用 SEM
- 只有横截面问卷时，中介检验只能提供统计上的间接效应，不能证明因果时序

### 1.6 分群与定位

- 按态度/需求/行为把消费者分组 → **聚类分析**
- 分组后描述特征、比较差异 → **交叉分析** + **方差分析**
- 市场细分、目标市场选择、品牌定位 → **STP 分析**
- 消费者决策链路 → **AISAS 模型**
- 消费价值结构 → **Sheth-Newman-Gross 消费价值模型**

### 1.7 评价与优先级

- 服务质量五维度 → **SERVPERF**
- 指标重要度 vs 表现 → **IPA 重要性—表现分析**
- 多指标综合评价、等级模糊 → **模糊综合评价**
- 指标赋权、专家判断 → **层次分析法 AHP**

### 1.8 文本与公开数据

- 评论词频、品牌提及 → **词频分析与词云**
- 关键词区分度、品牌文本对比 → **TF-IDF**
- 情感倾向 → **SnowNLP 情感分析**
- 主题结构 → **LDA 主题模型**
- 需要自行采集公开评论 → **Python 网络爬虫**（必须先确认平台条款与合规边界）

### 1.9 宏观与策略

- 政策、经济、社会、技术环境 → **PEST**
- 内外部态势 → **SWOT**（必须做交叉策略，不是四格清单）
- 营销组合 → **4P**
- 市场进入与竞争策略 → **STP** + **4P**

### 1.10 抽样

- 总体规模可估计、需要论证代表性 → **简单随机抽样与样本量测算**
- 多阶段、学校/院系/班级分层 → **多阶段抽样与 PPS 抽样**

## 2. 35 个模型速查

“最低样本”是经验门槛，不是绝对规则；最终还要看自变量个数、题项数、分组数和模型复杂度。

### 2.1 基础层（11 个）

| 模型 | 适用场景 | 最低样本 | 关键前提 | 不满足时 |
| --- | --- | --- | --- | --- |
| 描述性统计 | 现状、结构、均值/频率 | 30 | 样本有代表性、编码一致 | 补抽样或加权 |
| 李克特量表 | 态度、意愿、感知测量 | 30 | 同维度题项同向、反向题已转换 | 项目分析、删题 |
| Cronbach's α | 量表内部一致性 | 30 | 每维度 ≥3 题、题项正相关 | 题间相关、删题 |
| 百度指数分析 | 搜索关注度、市场潜力 | 无硬门槛 | 关键词有搜索量、口径一致 | 巨量算数、微信指数 |
| 词频分析与词云 | 评论/开放题高频词 | 100 | 语料相关、分词与停用词合理 | TF-IDF |
| AISAS 模型 | 注意—兴趣—搜索—行动—分享 | 100 | 各阶段可识别且互斥 | 描述统计 + 交叉分析 |
| Sheth-Newman-Gross | 功能/情感/社会/认知/情境价值 | 100 | 五类价值可操作化、量表可信 | 描述统计 + 回归 |
| PEST | 宏观环境 | 无硬门槛 | 每条判断有可查来源 | 仅作背景，不做统计推断 |
| SWOT | 内外部态势 | 无硬门槛 | 条目有数据/事实支撑、完成交叉 | PEST + 4P |
| STP | 细分、目标、定位 | 200 | 细分变量有区分度、目标可服务 | 聚类 + 交叉分析 |
| 4P | 产品/价格/渠道/促销 | 无硬门槛 | 建议有数据来源、指向同一定位 | STP |

### 2.2 进阶层（15 个）

| 模型 | 适用场景 | 最低样本 | 关键前提 | 不满足时 |
| --- | --- | --- | --- | --- |
| 简单随机抽样与样本量测算 | 论证样本代表性 | 无硬门槛 | 参数可溯源、设计效应有依据 | — |
| 卡方检验 | 分类变量差异/关联 | 100 | 观测独立、期望频数 ≥5 | Fisher 精确检验 |
| 交叉分析 | 分组分布、多重响应 | 100 | 编码清晰、多选题按响应集处理 | 卡方检验 |
| 方差分析 ANOVA | 多组均值差异 | 100 | 独立、残差近似正态、方差齐 | Welch ANOVA / Kruskal-Wallis |
| KMO 与 Bartlett | 量表效度、因子分析适用性 | 100 | 题项相关、样本为题项数 5–10 倍 | 项目分析 |
| 聚类分析 | 消费者分群、市场细分 | 200 | 特征标准化、K 值有依据 | K-Modes / 层次聚类 |
| 多元线性回归 | 连续因变量的影响因素 | 100 | 线性、独立、同方差、无强共线性 | 稳健标准误 / 变量变换 / 分样本 |
| 二元 Logistic 回归 | 二分类结果的影响因素 | 100 | 二分类因变量、无完全分离 | 惩罚似然 / 精确 Logistic |
| SERVPERF | 服务质量评价 | 200 | 成熟量表改编、维度信度可接受 | IPA / 描述统计 |
| IPA | 重要度—表现优先级 | 100 | 同时测重要度与满意度、分割线明确 | 描述统计 + 排序 |
| Python 网络爬虫 | 公开文本采集 | 100 | 遵守 robots.txt/平台协议、不抓个人信息 | 官方 API / 公开数据集 |
| SnowNLP 情感分析 | 中文评论情感倾向 | 100 | 中文语料、需人工抽样复核 | 人工编码 / 大模型标注 |
| TF-IDF | 关键词区分度、品牌文本对比 | 100 | 分词去停用词、比较组样本相当 | 词频分析 |
| 关联规则 | 多选共现、商品组合 | 200 | 0/1 矩阵、提升度 >1 | 交叉分析 |
| 随机森林 | 预测、特征重要性、非线性 | 300 | 训练/测试划分、特征完整、固定种子 | LightGBM / 回归 |

### 2.3 高阶层（9 个）

| 模型 | 适用场景 | 最低样本 | 关键前提 | 不满足时 |
| --- | --- | --- | --- | --- |
| 多阶段抽样与 PPS | 大规模、多层抽样框 | 无硬门槛 | 各级规模数据可得、阶段 2–3 层 | 分层随机抽样 |
| 主成分/因子分析 | 降维、结构效度 | 200 | KMO>0.7、Bartlett p<0.05、样本为题项数 5–10 倍 | PCA / 项目分析 |
| 层次分析法 AHP | 指标赋权、评价体系 | 无硬门槛 | 判断矩阵 CR<0.1、专家合理、同层 ≤9 指标 | 熵权法 / 因子权重 |
| 模糊综合评价 | 等级模糊的综合评价 | 100 | 权重来源明确、隶属度合理 | 加权平均 / TOPSIS |
| 结构方程模型 SEM | 中介、路径、潜变量 | 200 | 理论模型有依据、测量模型信效度合格 | 回归 + Bootstrap 中介 |
| LDA 主题模型 | 评论主题发现 | 500 | 语料数百至数千条、主题数有依据 | TF-IDF + 人工编码 |
| 弹性网络回归 | 高维变量筛选、共线性 | 200 | 标准化、交叉验证定 λ/α | 线性回归 / 岭回归 |
| LightGBM | 高精度预测、特征筛选 | 500 | 训练/测试划分、调参合理、固定种子 | 随机森林 / 弹性网络 |
| 贝叶斯网络 | 因果路径、情景推断 | 300 | 变量离散化、变量数 5–10、状态组合样本充足 | Logistic / 决策树 |

> 表中“最低样本”来自项目知识库 `engine/data/models.json`，用于生成文档时的门槛校验。不同教材与软件的标准略有差异，答辩时应说明依据。

## 3. 样本门槛的经验规则

除了模型表里的最低样本，还要看模型内部自由度：

| 场景 | 经验规则 |
| --- | --- |
| 多元线性回归 | 每个自变量至少 10–20 个有效样本；总量不少于 100 |
| Logistic 回归 | 每个自变量至少 10 个“较少发生”的类别样本（EPV） |
| 因子分析 / SEM | 样本量为题项数的 5–10 倍；SEM 建议 ≥200 |
| 卡方检验 | 每格期望频数 ≥5；2×2 表优先 Fisher |
| 聚类分析 | 总样本 ≥200，且每群不少于 30 |
| 文本分析 | 词频/TF-IDF ≥100 条；LDA ≥500 条；需人工抽样复核 |
| 分组比较 | 每组 ≥30，否则改用非参数检验或合并组别 |

当样本不足时，优先级是：**补样 > 合并类别 > 降级模型 > 缩小研究问题**。不要通过删除不利数据来“满足”前提。

## 4. 常见错配

| 错配 | 为什么错 | 正确做法 |
| --- | --- | --- |
| 定序因变量直接做线性回归 | 间距不等，残差分布异常 | 有序 Logistic / 转为二分类 / 作为连续变量并说明局限 |
| 两个分类变量做 SEM | 没有潜变量与路径结构 | 卡方 + 交叉分析 |
| 小样本（<100）做 SEM | 参数估计不稳定 | 回归 + Bootstrap，或缩小模型 |
| 用多次 t 检验做三组比较 | 第一类错误膨胀 | ANOVA + 事后检验 |
| 相关分析直接解释为因果 | 横截面数据无法证明时序 | 改为“关联”，或说明因果推断限制 |
| 把调节变量同时当自变量 | 共线性与解释混乱 | 中心化后放入交互项，明确主效应与调节效应 |
| 量表题未做信效度直接加总 | 测量不可靠 | Cronbach's α + KMO/Bartlett + 因子分析 |
| 文本情感分析不做人工复核 | 领域词与反讽误判 | 抽样人工编码，报告一致率 |
| 爬虫不说明合规 | 伦理与法律风险 | 只用公开数据、遵守平台协议、脱敏 |
| 模型越多越显得专业 | 每个模型都要有 RQ 与数据支撑 | 核心模型 6–12 个，其余列为可选 |

## 5. 在文档中如何解释一个模型

第 5.4 节的每个模型条目应包含六件事：

1. **解决什么问题**：对应哪个 RQ、什么类型的分析。
2. **为什么适用**：变量层级、数据结构、样本量、理论依据。
3. **需要什么数据**：变量、题项、编码、样本分组。
4. **前提与检验**：列出可执行的检验（正态性、方差齐性、VIF、KMO、期望频数等）。
5. **结果怎么读**：关键系数、p 值、效应量、拟合指标的解释口径。
6. **备选方案**：前提不满足或样本不足时怎么办。

示例：

> 多元线性回归用于 RQ3，检验产品品质、价格感知、门店环境、品牌形象对购买意愿的影响。因变量为 4 题李克特均值，近似连续；自变量均为量表均值。样本 461 份，按每个自变量 10–20 例的经验规则满足要求。需检验线性、残差正态、同方差与 VIF<5；若方差不齐，使用稳健标准误；若存在强共线性，删除或合并构念。

## 6. 本科生竞赛的取舍

- 核心模型控制在 6–12 个：描述性统计、信度效度、1–2 个主分析模型、1 个文本/二手方法、1 个策略框架通常足够；纯问卷研究以 6–10 个为宜。
- 优先选择能解释清楚、能复现、能回答 RQ 的方法，而不是最新颖的方法。
- 高阶模型必须配降级方案，并在答辩中说明为什么需要它。
- 每个模型都要有“如果前提不满足怎么办”的答案。
- 不要为了模型数量牺牲问卷质量与样本代表性。
