# 数据需求速查

## 1. 输入

默认 `doc/input/research_brief.md`，UTF-8，Markdown 或 JSON。Markdown 由简单 frontmatter + `##` 章节组成；`<!-- -->` 注释会被忽略。没有“研究问题”时用“研究目标”替代，两者都没有会校验失败。

### 1.1 frontmatter

| 字段 | 说明 |
| --- | --- |
| `project_name` | 必填，项目名称 |
| `target_population` / `survey_unit` | 目标总体 / 调查单位 |
| `industry` / `region` / `research_type` | 行业、区域、研究类型 |
| `data_sources` | 列表，如 `[一手问卷, 公开文本/评论]` |
| `survey_mode` | 如“线上为主” |
| `confidence_level` / `margin_error` | 默认 0.95 / 0.05 |
| `expected_proportion` | 默认 0.5（最保守） |
| `population_size` | 留空按无限总体 |
| `design_effect` / `response_rate` | 默认 1.2 / 0.9 |
| `budget_cny` / `timeline_weeks` / `team_size` | 预算、周期、团队人数 |

只支持单行键值与行内列表，不支持 YAML 嵌套或多行字符串。

### 1.2 章节与别名

| 内容 | 可识别标题 |
| --- | --- |
| 研究背景 | 研究背景、项目背景、背景、研究缘起 |
| 研究问题 | 研究问题、核心问题、研究议题、RQs |
| 研究目标 | 研究目标、研究目的、研究任务、Objectives |
| 核心构念 | 核心构念、研究变量、变量设计、构念、变量 |
| 已有假设 | 研究假设、已有假设、假设 |
| 方法偏好 | 分析方法倾向、拟用方法、方法偏好、分析方法 |
| 约束 / 备注 | 约束条件、限制条件 / 补充说明、备注 |
| 分层配额 | 分层、配额、分层配额、抽样分层 |
| 基本信息 | 基本信息、项目信息、研究概况 |

“基本信息”中的 `键：值` 可补充 frontmatter，但不覆盖已有值。

### 1.3 研究问题

支持 `1.`、`-`、`*`，编号 `RQ1：` 可省略。关键词决定问题类型：描述、差异/比较、相关/关系、影响/因素、中介/通过、调节/交互、分群、评价/评分、文本/评论、预测。类型识别错误时改写问题措辞，再用 `validate` 检查。

### 1.4 核心构念表

至少包含“构念”和“角色”两列；推荐列：构念、角色、操作化定义、题项数、量表、测量层级、数据来源、维度、备注。

- 角色：因变量、自变量、中介变量、调节变量、控制变量、筛选变量、探索性变量。
- 测量层级：定类、定序、连续、文本、多重响应。
- 一个变量只设一个主角色；既调节又分组时在备注说明，不重复建行。
- 李克特构念建议 ≥3 题；控制变量通常 3–6 个，不宜堆砌。

### 1.5 配额、假设与 JSON

```markdown
## 分层配额

- 大一：25%
- 大二：120人
```

比例会归一化；纯数字 ≤100 视为百分比，人数写成“120人”。已有假设时用 `- H1：……`，引擎不再自动生成，只补变量、方法与理论绑定。

```json
{
  "project_name": "大学生咖啡消费研究",
  "target_population": "武汉市高校在校大学生",
  "research_questions": [{"qid": "RQ1", "text": "消费频率呈现什么特征？"}],
  "constructs": [{"name": "购买意愿", "role": "dependent", "items": 4, "scale": "5 级李克特", "measure": "连续"}],
  "strata": [{"name": "大一", "ratio": 0.25}]
}
```

`role` 用英文：dependent / independent / mediator / moderator / control / screening / exploratory。

## 2. 输出

默认 `doc/output/data_requirement.md`，固定六项核心产出：

| 要求 | 章节 | 关键内容 |
| --- | --- | --- |
| 变量确定 | 3 | 角色、操作化、测量层级、题项、变量字典、变量—模型映射 |
| 样本参数 | 4 | 公式、参数、n0、FPC、设计效应、有效率、配额、敏感性、模型门槛 |
| 模型方法（重点） | 5 | 每题主模型；每个模型的理由、变量、前提、解读、备选 |
| 假设 | 2 | IV/DV/中介/调节、方向、检验方法、理论依据 |
| 调查渠道 | 6 | 主/辅/备渠道、触达、配额、成本、节奏、合规 |
| 质控措施 | 7 | 设计、抽样、执行、清洗、分析、交付六阶段规则 |

其他章节：0 摘要、1 研究概述、8 数据交付、9 进度与风险、10 待确认、附录 A–C。第 10 章必须披露默认值与推断项。

样本量公式：

```text
n0 = z² · P(1−P) / d²
n0' = n0 / [1 + (n0 − 1) / N]        （有限总体）
n_eff = n0' · deff
n_plan = ceil(n_eff / r)
```

每个核心模型条目应包含：定位、对应 RQ 与变量、适用理由、公式/口径、步骤、前提、结果解读、备选。假设与模型的方法必须一致。

## 3. 模型速查

| 场景 | 推荐 | 最低样本/关键前提 |
| --- | --- | --- |
| 现状、均值、频率 | 描述性统计 | 30；样本有代表性 |
| 态度/意愿量表 | 李克特 + Cronbach's α | 30；每维 ≥3 题且同向 |
| 量表效度、降维 | KMO/Bartlett + 因子分析 | 200；KMO>0.7、样本为题项 5–10 倍 |
| 分类变量差异/关联 | 卡方 + 交叉分析 | 100；期望频数 ≥5 |
| 多组均值差异 | ANOVA + 事后检验 | 每组 ≥30；独立、近似正态、方差齐 |
| 连续 Y 的影响因素 | 多元线性回归 | 100；每自变量 10–20 例，无强共线 |
| 二分类 Y 的影响因素 | 二元 Logistic | 100；EPV ≥10，无完全分离 |
| 定序 Y | 有序 Logistic | 100；平行线假设 |
| 多分类 Y | 多项 Logistic | 100；类别样本充足 |
| 中介/调节 | 分层回归 + Bootstrap；复杂时 SEM | 200；路径有理论依据 |
| 潜变量/路径 | SEM | 200；测量模型信效度合格 |
| 消费者分群 | 聚类分析 | 200；标准化、K 值有依据 |
| 预测/特征重要性 | 随机森林 / LightGBM | 300/500；训练测试划分、固定种子 |
| 词频、关键词、情感 | 词频 / TF-IDF / SnowNLP | 100；分词与人工复核 |
| 评论主题 | LDA | 500；主题数有依据 |
| 服务质量/优先级 | SERVPERF / IPA / 模糊综合评价 | 100–200；权重来源明确 |
| 多项选择共现 | 交叉分析 / 关联规则 | 100–200；按响应集处理 |

样本不足时优先级：补样 > 合并类别 > 降级模型 > 缩小研究问题。不要删不利数据来“满足”前提。

## 4. 复核清单

- [ ] 每个 RQ 有假设或探索性落点，IV/DV/中介/调节一致。
- [ ] 因变量是结果变量，不是原因、分组变量或中介。
- [ ] 每个核心构念有定义、题项、量表、测量层级。
- [ ] 李克特题项同向，反向题已标注转换规则。
- [ ] 控制变量有纳入理由，数量合理。
- [ ] 变量字典字段与问卷题号、数据集字段一致。
- [ ] 样本量公式、参数、结果、敏感性分析一致。
- [ ] 配额合计 100%，且每层可达。
- [ ] 每个核心模型的最低样本满足，不满足时有补样或降级方案。
- [ ] 5.3 每个 RQ 至少一个主模型，模型与问题类型匹配。
- [ ] 每个模型的前提可检验，不满足时有明确备选。
- [ ] 核心模型 6–12 个（纯问卷 6–10 个），没有“为用模型而用模型”。
- [ ] 渠道能触达目标总体，有触达方式、配额、成本、负责人、时间。
- [ ] 无效问卷规则可执行：时长、直线作答、逻辑矛盾、甄别题、重复 IP。
- [ ] 质控覆盖六阶段，责任到人，验收标准量化。
- [ ] 第 10 章逐条列出默认值与推断项。
- [ ] 表格列数一致，Mermaid 可渲染，编号与交叉引用正确。
- [ ] 没有编造文献、数据、统计结果或平台政策。

## 5. 常见错配与排错

| 问题 | 正确处理 |
| --- | --- |
| 定序 Y 直接做线性回归 | 有序 Logistic；或说明按连续处理的局限 |
| 两个分类变量做 SEM | 卡方 + 交叉分析 |
| 小样本（<100）做 SEM | 回归 + Bootstrap，或缩小模型 |
| 多次 t 检验比较三组 | ANOVA + 事后检验 |
| 相关分析解释为因果 | 改为“关联”，说明横截面限制 |
| 调节变量同时当自变量 | 中心化后放交互项，明确主效应 |
| 量表未做信效度就加总 | Cronbach's α + KMO/Bartlett |
| 文本情感分析不做人工复核 | 抽样人工编码，报告一致率 |
| 配额用了表格 | 改成 `- 层名：25%` 列表 |
| 输入无法解析 | 检查路径、UTF-8、frontmatter 与必需章节 |

更多模型知识以 `engine/data/models.json` 与生成文档为准；本文只用于快速判断与复核。
