# 模型匹配

目标：用最少的追问，给出一个能执行的主模型，并说明为什么不是另一个。默认输出控制在 10 行左右，不写完整研究方案。

## 交互流程

### 1. 先读已有信息

用户给了文件路径或文档，先读文档；否则从提示词中提取：

- **因变量 Y**：定义、题项数、量表、取值（连续/二分类/多分类/定序/计数/文本/多重响应）。
- **自变量 X**：数量、测量层级、是否含分组变量、中介变量、调节变量、控制变量。
- **研究目的**：描述现状、组间差异、变量关联、影响因素、机制（中介/调节）、分群、评价、预测。
- **设计**：是否配对/前后测、是否重复测量、是否潜变量、是否多个因变量。
- **样本量 n**：有效样本，不是发放量。

能从“5 级李克特、4 个题项”“是否复购”“月消费金额”等描述推断的，不要重复问。

### 2. 只问会改变结论的问题

一次最多问 3 个，合并成一份清单：

1. 因变量的测量方式或取值是什么？
2. 这次主要想回答“有没有差异、有没有影响、能不能预测、还是只看现状”？
3. 有效样本大概多少？是否有分组、前后测或重复测量？

信息不足但用户要求直接给结果时，按最可能的假设先给临时结论，并在“需确认”中写明假设。不要因为一个次要信息缺失就停止。

### 3. 按顺序判断

1. **先看 Y 的类型**：它决定模型家族。
2. **再看研究目的**：同样是连续 Y，组间差异用 t/ANOVA，影响因素用回归，预测用机器学习。
3. **看 X 的结构**：分组变量、连续自变量、中介/调节、潜变量。
4. **看设计**：独立样本还是配对/重复测量。
5. **看样本量与前提**：不够就降级，不硬上。
6. **看本科生可执行性**：能用回归讲清楚，就不要为了“高级”上 SEM。

## 快速匹配表

| 数据与目的 | 一级推荐 | 二级推荐（基础/辅助） |
| --- | --- | --- |
| Y 连续，多个 X，研究影响 | 多元线性回归 | 描述性统计 + 相关分析 + 量表信度 |
| Y 连续，1 个二分类分组变量 | 独立样本 t 检验 | 描述性统计 + 箱线图 |
| Y 连续，1 个三组以上分组变量 | 单因素方差分析 + 事后检验 | 描述性统计 + 方差齐性检验 |
| Y 连续，分组 + 需要控制协变量 | 协方差分析或回归 + 虚拟变量 | 描述性统计 |
| Y 连续，同一批人前后测 | 配对样本 t 检验 | 描述性统计 |
| Y 二分类，多个 X，研究影响 | 二元 Logistic 回归 | 描述性统计 + 交叉表 + 卡方 |
| Y 二分类，只看组间差异 | 卡方检验（2×2 优先 Fisher） | 交叉表 |
| Y 多分类，多个 X | 多项 Logistic 回归 | 交叉表 + 卡方 |
| Y 定序，多个 X | 有序 Logistic 回归 | 描述性统计 + 非参数检验 |
| Y 计数（次数、人数） | Poisson / 负二项回归 | 描述性统计 |
| 验证 X→M→Y 或 W 改变 X→Y | 分层回归 + Bootstrap；复杂时 SEM | 描述性统计 + 相关 + 信度 |
| 潜变量、测量模型、多条路径 | SEM / CFA | Cronbach's α + KMO/Bartlett |
| 目标是预测而非解释 | 随机森林 / LightGBM | 线性或 Logistic 基线模型 |
| 按特征给消费者分群 | 聚类分析 | 描述性统计 + 方差分析/交叉表 |
| 文本、评论、开放题 | 词频/TF-IDF/情感分析/LDA | 人工抽样复核 |
| 没有明确 Y，只看现状 | 描述性统计 | 频数表 + 可视化 |
| 服务质量/满意度评价 | SERVPERF / IPA / 模糊综合评价 | 描述性统计 + 信度 |

“二级推荐”是支撑主模型的基础分析或合理备选，不是第二个主模型。

## 输出格式

默认使用这个结构，不要加长文：

```text
一级推荐：多元线性回归
理由：因变量为连续变量，有多个连续/定类自变量，目的是分析影响因素
二级推荐：描述性统计 + 相关分析
备选/降级：若残差不满足正态或方差齐性，改用稳健标准误；样本不足时先做相关与分组比较
需确认：因变量是否按连续处理？有效样本是否≥100？
```

如果用户明确要求详细方案，再补充变量编码、前提检验、软件步骤与结果解读。

## 关键判断规则

- **李克特量表**：单题通常按定序处理；同一维度 ≥3 题且加总/取均值后，可近似连续，但要说明这是研究惯例，不是数学上的连续。
- **定序 Y**：不要默认线性回归；优先有序 Logistic。只有明确把量表均值当连续变量时才用线性回归。
- **二分类 Y**：优先 Logistic；不要用线性回归。样本很少或类别极不平衡时，报告 EPV 与置信区间。
- **多个 X**：回归比多次单变量检验更合适；分组变量放进模型时用虚拟变量。
- **中介/调节**：横截面问卷只能提供统计关联，不能证明因果时序；中介优先 Bootstrap，调节用中心化后的交互项。
- **样本门槛**：回归 ≥100 且每个自变量约 10–20 例；t/ANOVA 每组 ≥30；Logistic 每个自变量至少 10 个较少类别样本；卡方每格期望频数 ≥5；因子分析/SEM 样本为题项数 5–10 倍，SEM 建议 ≥200；聚类 ≥200；LDA ≥500 条文本。
- **不满足前提时**：补样 > 合并类别 > 改用稳健方法/非参数方法 > 缩小研究问题。不要删掉不利数据来“满足”前提。
- **相关不等于因果**：只有横截面相关时，输出“关联”而不是“影响”。

## 示例

输入：因变量是购买意愿，4 个 5 级李克特题项；自变量是产品品质、价格感知、品牌形象，各有 4–5 个 5 级题项；有效样本 400；想看影响因素。

```text
一级推荐：多元线性回归
理由：Y 为多题项量表均值，可近似连续；X 为多个连续/量表变量；目的是影响因素分析
二级推荐：描述性统计 + 相关分析 + Cronbach's α
备选/降级：残差不正态或方差不齐时用稳健标准误；共线性严重时合并构念或改用弹性网络
需确认：购买意愿是否按连续变量处理？三个自变量的 VIF 是否已检查？
```

输入：因变量是“是否复购”（是/否）；自变量是满意度、价格感知、年龄；样本 180。

```text
一级推荐：二元 Logistic 回归
理由：Y 为二分类，X 同时包含连续与定序变量，适合估计各因素对复购概率的影响
二级推荐：描述性统计 + 交叉表 + 卡方检验
备选/降级：若某自变量类别样本过少，合并类别；EPV 不足时减少自变量或改用惩罚 Logistic
需确认：复购人数与未复购人数各多少？是否存在完全分离？
```

## 边界

- 本 skill 只做模型匹配，不生成数据需求文档、不执行统计计算、不编造结果。
- 变量定义含混时先确认测量层级；测量层级错了，后面的模型都会错。
- 推荐以本科市场调查可执行性为准；高阶模型必须同时给出降级方案。
