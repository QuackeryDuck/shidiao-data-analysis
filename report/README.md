# 报告与交付目录（report/）

存放图表、表格、问卷、最终报告与答辩素材。

建议结构：

```text
report/
├── figures/              # 分析图表（PNG/SVG），按章节编号
├── tables/               # 结果表（CSV/Excel）
├── questionnaire/        # 问卷定稿与变更记录
├── data_requirement/     # 数据需求文档归档（按版本）
├── final_report/         # 参赛报告正文与附件
└── README.md
```

约定：

- 图表文件名体现内容与版本：`fig_5_1_path_model_v2.png`。
- 图表必须能追溯到数据版本与生成脚本；不要只保存截图。
- 问卷每次修改保留版本与修改说明，避免分析时题号错位。
- 数据需求文档、数据字典、分析代码与最终报告一起归档。
- 提交前检查：图表编号与正文一致、样本量标注一致、显著性标注完整、参考文献格式统一。
